# Regression coverage map

The standard suite is deterministic and does not require paid Codex calls. The completed run used the host Playwright installation and loopback permission, so browser tests ran instead of being skipped.

| Requirement | Regression coverage |
|---|---|
| Strict Codex schemas, optional/null handling, local references, invalid schema classification | `tests/test_evidence_gates.py`: `test_optional_fields_become_required_nullable_recursively`, `test_local_defs_refs_and_nested_refs_are_inlined`, `test_unresolvable_and_remote_refs_fail_with_schema_diagnostics`, `test_compiled_production_findings_schema_validates_strict_response`, `test_invalid_top_level_schema_is_classified_before_invocation` |
| Structured response, evidence references, complete redacted failures, image attachment | `tests/test_evidence_gates.py`: `test_image_argument_is_attached_and_recorded_in_invocation`, `test_backend_failure_preserves_redacted_complete_stderr`, `test_unsupported_image_is_rejected_before_model_invocation`, `test_production_schema_and_snapshot_evidence_reject_invalid_citations`; `tests/test_orchestrator.py`: `test_malformed_specialist_output_is_recorded_as_a_limitation` |
| Route discovery, browser attachment, viewport-sized screenshots, overflow metadata, manifest integrity, browser degradation | `tests/test_evidence_gates.py`: `test_source_route_discovery_normalizes_dot_segments`, `test_bad_route_does_not_abort_valid_capture_and_capture_records_actual_content`; `tests/test_deep_audit.py`: `test_browser_capture_collects_explicit_routes_and_runtime_metadata`, `test_authorized_server_starts_readies_and_only_its_process_is_stopped`, `test_existing_server_is_not_duplicated_and_remote_start_is_rejected`; `tests/test_orchestrator.py`: `test_standard_responsive_viewports_and_browser_degradation` |
| Screenshot-to-model image arguments and screenshot-backed output references | `tests/test_evidence_gates.py`: `test_image_argument_is_attached_and_recorded_in_invocation`, `test_visual_schema_citations_are_limited_to_attached_route_viewport_images`; separate live one-image integration in `benchmark-results/after/one-image-integration.json` |

| Guided persistence, resume, explicit end, separate approvals, implementation patch safety | `tests/test_deep_audit.py`: `test_guide_persists_instructions_continues_audit_then_explicitly_ends`, `test_end_of_input_persists_pending_decision_and_can_resume`, `test_direction_confirmation_does_not_authorize_implementation`; `tests/test_orchestrator.py`: `test_interrupted_audit_can_resume_and_retry`, `test_visual_and_behavior_decisions_are_separate_and_mockup_does_not_authorize_implementation`, `test_out_of_scope_patch_is_rejected_before_git_apply`, `test_stale_file_baseline_blocks_implementation_authorization` |

Real Codex output-schema/image interpretation is exercised separately to avoid charging the ordinary test suite for model calls. The synthetic app's broader safe workflows are recorded in `interaction-runtime-evidence.json` and `interaction-runtime-audit.md`.
